# Proyecto-final_Logica-y-algoritmos
Ejemplo de proyecto final para el modulo Logica y Algoritmos, en el que se aplicaran los temas vistos en clase

## Descripcion 
Este proyecto es una aplicacion basica desarrollada en JS que permite gestionar y analizar el inventario de platillos de un restaurante 

Su objetivo es servir como practica para aprender conceptos y aplicar logica y algoritmos
